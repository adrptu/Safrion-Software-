# Backlog

O backlog vive nas **Issues do GitHub**. Os modelos estão em `.github/ISSUE_TEMPLATE/`. Este arquivo só explica as convenções.

- **Tipos:** tarefa (incremento com critérios de aceite), defeito (reprodução e evidência) e decisão (precisa do proprietário).
- **Cada issue cita os IDs do PRD que atende** (RN, RF, CMD, CAL, AC, DS…). Issue sem vínculo com o PRD precisa de justificativa.
- **Prioridade:** P0 a P3, com as definições do `AGENTS.md`.
- **Rótulos sugeridos:** `tipo:tarefa`, `tipo:defeito`, `tipo:decisao`, `P0`…`P3`, `area:<módulo>`, `bloqueado`, `precisa-proprietario`.
- **Pronto para começar:** problema, resultado esperado, escopo, dependências e critérios de aceite observáveis.
- **Pronto para encerrar:** critérios verificados na versão exata, evidência anexada, revisão do outro agente registrada e `docs/STATUS.md` atualizado.
