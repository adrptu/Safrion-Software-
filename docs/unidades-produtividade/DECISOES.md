# Unidade de produtividade · decisões tomadas sem o proprietário

Cada decisão vale até o proprietário mudar. Nenhuma delas é aprovação dele (AGENTS §2).
- **Rótulo:** especificado.
- **Referências:** `ESPECIFICACAO.md` (§, R-Unn, K-Unn, AC-x).
- **Base:** `47ff754`. Nada foi lido de `prototipo/v43`, `c9d61266` ou `d22da69`.

**Registro do requisito (contrato, item 8).**
- **Pedido do proprietário:** em 10/10/2026, trazido pelo Codex em UNIDADES-PROD-20261010-01 (PR #47, comentário 6093638004): «Coloque opções para todas culturas em kg/ha, ton/ha, sc 60 kg/ha, etc.».
- **Precisões do Codex (6093701812):**
  - a base kg/ha vale só para o indicador em massa;
  - nenhum fato persistido é trocado por taxa;
  - L, frutos e caixas não viram kg;
  - a agregação conta a área uma vez só.
- **PRD:** não foi reaberto. O requisito fica aqui até a consolidação do conjunto, fora da v55, e entra na versão seguinte.
